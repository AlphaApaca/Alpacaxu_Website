- 桌面与手机上的留白、字体、暗色配色和交互动效。
- 跨页动画改善视觉连续性，但尚未进行真实慢网或耗时统计；不保证网络速度变快。慢网下首页仍可能短暂先显示静态中文、随后应用保存的英文。

- Giscus 配置及稳定关联键保留；实际登录和发言仍由用户完成。
- 各部分内容增删改的位置与交付说明，按用户要求留到这轮视觉/交互验收后再一起商议；现有预备说明不代表已经完成交接。
- 本地验收不能替代远程验收；推送后需检查对应提交的 Vercel 预览与检查结果。远程结果记录在草稿 PR 中，不要合并未验收的视觉试验。
