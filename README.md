# Mingyang Xu Personal Website

零依赖的中英双语个人网站，展示许明阳的机器人规划评测、ROS2 导航项目、实习、论文与技术笔记。可直接用浏览器打开，也可部署到静态托管平台。

## 文件结构

- `index.html`：首页、代表项目、实习与论文、文章列表
- `articles/`：文章详情页
- `styles.css`：全站样式和响应式布局
- `script.js`：中英双语、深色模式和文章搜索
- `assets/hero-workspace.png`：首屏视觉资产
- `assets/avatar.png`：个人证件照

## 本地预览

直接打开 `index.html`，或在项目目录运行：

```bash
python3 -m http.server 8080
```

然后在浏览器中打开本地服务器显示的地址。

## 内容维护

- 同步修改 `index.html` 的默认文案和 `script.js` 中的中英翻译，避免未加载脚本时出现旧内容。
- 网站以最新确认的简历事实为准；MuJoCo 项目是规划可行性评测，不是 VLA 策略训练。V.I.S.O.R. 是团队项目，个人贡献主要是导航验证与调优。
- 未确认或不用于求职的经历不进入公开页面；项目证据链接必须先确认可公开访问，不使用占位链接。
- 团队项目的仓库入口仅在能够公开访问时展示。
